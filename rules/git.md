# Git

- 编辑前检查工作区，保留用户和并发任务的无关改动。
- 修改文件的实现任务必须以一次 Git 提交结束，并在回复中报告提交哈希。
- 只暂存当前任务相关的文件或代码块，不夹带无关修改。
- 一个提交只表达一个可独立验证的变更。
- 不擅自推送、强制更新、重置、清理或改写历史。
- 提交前运行与改动风险匹配的检查，并在说明中记录验证结果。
- 提交信息说明发生了什么及原因，避免 `fix`、`update` 等空泛描述。
- 只读任务和没有文件变化的任务不创建空提交。
