## 1. RTK — 终端命令输出压缩

RTK 压的是命令输出

作用：过滤终端输出的注释、空行、ANSI 码、进度条、重复告警，压“命令输出送往上下文”的量。实测 30 分钟会话节省约 **88.9%**。

安装：

```bash
# macOS（推荐）
brew install rtk

# Linux / WSL
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/master/install.sh | sh

# 按 Agent 启用
rtk init -g                    # Claude Code（默认）
rtk init -g --codex            # Codex
rtk init -g --gemini           # Gemini CLI
rtk init -g --agent cursor     # Cursor
rtk init -g --agent omp         # omp（Fork 版）
```

重启 Agent 后生效，透明过滤，无感知。

> 注意：装完用 `rtk gain` 验证；若命令不存在，可能是装了同名的 Rust Type Kit，需卸载重装。

常用命令：

* `rtk gain`（看节省统计）
* `rtk gain --history`
* `rtk discover`（扫描未覆盖的命令）
* `rtk git status`
* `rtk git diff`
* `rtk test cargo test`
* `rtk vitest run`

## 2. headroom — 全量上下文压缩

作用：压所有进上下文的内容（文件、工具返回值、会话历史）。可逆压缩（CCR）：原始数据留本地，按需取回。实测节省 **47–92%**，压缩后准确率不降。代理层还含 CacheAligner（稳定前缀促缓存命中）、ContentRouter（按类型分流）。

安装：

```bash
pip3 install "headroom-ai[all]"

# 基础接入
headroom wrap omp
headroom wrap codex

# 恢复
headroom unwrap omp

# 验证
headroom doctor
headroom perf
# 查看 dashboard
headroom dashboard

# 推荐：同时开启跨 session 记忆 + 代码图谱集成
headroom wrap omp --memory --code-graph
```

***

```bash
# 先这样试
pip3 install "headroom-ai[all]"

cd 一个真实项目

headroom wrap omp

# 做 3~5 个你平常会做的长任务

headroom doctor
headroom perf
headroom dashboard
```

MCP 模式（不想用 wrap）：

```bash
headroom mcp install
```

注册三个工具：`headroom_compress`、`headroom_retrieve`、`headroom_stats`。

* Input tokens
* 任务完成率
* 需要 retrieve 的次数
* 错误 / 漏信息次数

**Token 下降 + 完成率持平，Headroom 就有实用价值。**
**Token 下降 + 漏信息增加，压缩策略仍需要调。**

## 3. context-mode — MCP 工具输出压缩 + 会话连续性

作用：解决 MCP 工具返回值过大（如 Playwright 快照 56KB）。四能力：

* Sandbox 工具输出（**98% 压缩**，315KB→5.4KB）
* 跨 `/compact` 会话连续性（本地 SQLite + FTS5）
* `ctx_execute()` 用代码代替读文件
* 不干预输出格式

```bash
npm install -g context-mode
```

重启 omp（或 `/reload-plugins`）后生效。

验证：`/context-mode:ctx-doctor`（全部 \[x] 即正常）、`/context-mode:ctx-stats`（按工具看节省）、`/context-mode:ctx-insight`（本地看板）。

## 4. Graphify — 代码知识图谱（Skill 形态）

作用：Tree-sitter 解析代码建图谱，AI 查图代替反复读文件。官方称比直接读文件减少 **71.5 倍 Token**。生成 `graphify-out/` 下三份产物（`graph.html` / `GRAPH_REPORT.md` / `graph.json`）。

安装：

```bash
# 安装
uv tool install graphifyy
# 或
pipx install graphifyy

# 注册到 omp
graphify install --platform omp
# 或
graphify omp install
```

在 omp 里执行 `/graphify` 扫描项目。支持 30+ 语言，git hook 增量更新。

## 5. CodeGraph — 持久化图数据库（MCP 形态）

作用：MCP Server + 持久化图数据库（Neo4j/KuzuDB）。7 个真实仓库 benchmark：平均 **62% 更少 Token、88% 更少 Tool Call、44% 更低成本、53% 更快**。**大型 Rust/TypeScript 项目收益最显著；中小 Java/Go 项目收益有限。**

> 注意：官方承认指标衡量“处理量”，不衡量长会话结束时上下文残留——长会话里图返回的密集负载残留反而更高（约多 80%），需留预算。

安装：

```bash
# npm 安装
npm i -g @colbymchenry/codegraph

# 初始化项目
cd your-project
codegraph init -i
```

手动配置 mcp：

```json
{
  "mcpServers": {
    "codegraph": {
      "type": "stdio",
      "command": "codegraph",
      "args": ["serve", "--mcp"]
    }
  }
}
```

核心工具：

* `codegraph_context`（找入口）
* `codegraph_trace`（追调用路径）
* `codegraph_impact`（重构前影响分析）
