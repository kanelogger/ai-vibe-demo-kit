# AGENTS 规则维护

只读取与当前维护任务有关的目标文件、直接引用和项目配置。先确认作用域与来源，再分类、起草和做确定性检查。

按风险选择流程：

- 普通模式：只读审计、仓库内可逆编辑和无生产访问的本地验证。完成相关调查、改动、必要检查和失败修复后报告结果。
- 严格模式：用户级规则变更、发布、生产写入、外部系统变更和破坏性操作。加载对应 reference，执行独立审阅、人工批准、写入前保护和新上下文验收。

完成标准：满足任务验收标准，运行必要的相关验证，处理本次改动导致的失败，并报告未执行、失败、过期或未知的检查。

按需加载：

- 审阅包、分类和证据：`references/review-package.md`
- 高风险写入、备份和恢复：`references/safe-write.md`
- 新上下文加载验收：`references/verification.md`
